# 能力域清单模板（Ability Domains）

> 回归走查的能力域清单骨架。回归按能力（而非文件）组织；本模板建立并维护清单。

## Use when

- 初始化项目能力域清单时（init.sh 复制到 docs/ability-domains.md）
- 新能力合入同步登记、回归漏检回写时

## 建立方法

| 规则 | 说明 |
|------|------|
| 从用户旅程切分 8-12 域 | 启动 → 核心功能（1-2 个主干能力按用户任务切） → 辅助功能 |
| 粒度测试 | 每域一轮走查 ≤15 分钟；太大再拆、太小合并 |
| 每域四件套 | 验证点列表（★ 快速必测标）/ 操作路径 / 通过标准 / 证据落盘路径 |

## 域条目格式

手段编码：UI 元素状态观察 · LOG 日志关键字 · DATA 本地数据直查 · PERF 性能指标 · MANUAL 人工验收。

```markdown
## <能力域名>

| # | 验证点 | 操作路径 | 通过标准 | 手段 |
|---|--------|----------|----------|------|
| ★1 | <快速回归必测点> | <步骤序列> | <可核对预期> | UI+LOG |
| 2 | <完整回归补充点> | <步骤序列> | <可核对预期> | DATA |
```

## 起始骨架（复制后按项目填充）

| 能力域 | ★ 快速回归必测点（示例） | 完整回归补充 | 手段 |
|--------|--------------------------|--------------|------|
| 启动与崩溃安全 | 冷启动应用可见；崩溃缓冲区为空 | 低内存杀进程后状态恢复 | PERF+LOG |
| 连接管理 | 连接/断开/重连；事件流持续到达 | 多服务器切换、失败恢复 | UI+LOG |
| 列表与导航 | 列表渲染正确；进入详情；滚动无卡死 | 搜索/过滤/边界滚动双向 | UI+PERF |
| 核心业务界面 | 主路径可用 | 失败/重试/并发路径 | UI+MANUAL |
| 数据存储 | 读写落盘；重启保留 | 迁移/损坏自愈/限量裁剪 | DATA+LOG |
| 状态与事件 | 状态机流转正确 | 事件丢失兜底/状态恢复 | LOG+UI |
| 本地化与发版检查 | i18n 检查通过 | 版本真相源/产物签名核对 | LOG+DATA |

## 维护规则

| # | 规则 | 违反后果 |
|---|------|----------|
| 1 | 新能力合入时同步登记（或新建域），不得代码先进清单后补 | 新能力回归漏测 |
| 2 | 季度复查：删废弃域、补演进新点 | 清单腐化 |
| 3 | 回归漏检时回写该验证点（清单是活的） | 同一漏检反复 |
