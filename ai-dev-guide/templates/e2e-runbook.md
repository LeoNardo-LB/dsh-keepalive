## 填写规则

| # | 规则 | 违反后果 |
|---|------|----------|
| 1 | 期望与实操两文档分离存放 | 混用 → 无法区分「没测到」与「没达到预期」 |
| 2 | 核心断言优先 SCR，视觉断言用 DYN | 全 DYN → 不可重复、回归成本高 |
| 3 | 同一结论 ≥1 SCR + ≥1 DYN 交叉印证 | 单手段结论 → 自证自洽、漏检 |
| 4 | 实操只记事实，不改写历史轮次 | 改写历史 → 差异分析失真 |
| 5 | 每项偏离记录问题归属（操作 / 观测 / 代码） | 归属不清 → 修复方向错误 |
| 6 | 代码问题不打补丁，转 bug-analysis 根治 | 现场打补丁 → 债务累积、复发 |
| 7 | 未达成项跟踪到状态收敛（待重测 / 已修复 / 已登记） | 悬而未决 → 回归盲区遗留 |
| 8 | 档位联动（[verify.md](../workflows/verify.md) §5） | 脱离档位 → 验证强度与变更不匹配 |
