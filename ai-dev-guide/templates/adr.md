# 架构决策记录模板（ADR Template）

> 架构决策的记录格式：把「为什么这么定」沉淀为可追溯文档，避免后人推翻或误改承重决策。
> 配合 [../standards/architecture.md](../standards/architecture.md)（承重规则）与 ../meta/doc-governance.md（存放与生命周期）使用。

## Use when

- 做出下节「四类触发场景」任一决策时
- 已有 ADR 状态变更（被替代 / 废弃）时

## 何时必须写 ADR

| 触发场景 | 判定问题 | 违反后果 |
|----------|----------|----------|
| 跨层接口 | 是否改变分层依赖方向 / 模块边界 / 公共接口？ | 依赖方向漂移 → 回归（见 [../standards/architecture.md](../standards/architecture.md)） |
| 存储方案 | 是否新增/更换本地或远端存储、改变持久化格式？ | 数据迁移不可逆 → 数据重建 |
| 引入新依赖 | 是否引入新第三方库 / 框架 / 引擎？ | 依赖沉淀 → 长期维护成本 |
| 不可逆决策 | 回退成本是否高（签名体系 / 版本体系 / 数据迁移 / 对外协议）？ | 回退即事故 → 全员受影响 |

> 用判定问题自查，「是」即写 ADR；ADR 是记录而非审批，宁多勿漏。

## 模板本体

````markdown
# <序号>. <决策标题>

| 字段 | 值 |
|------|----|
| 状态 | <提议 / 已接受 / 已废弃 / 被替代> |
| 日期 | <YYYY-MM-DD> |
| 决策者 | <人 / agent / 团队> |

## 上下文

<为什么需要决策：现状、约束、触发事件，2-5 句，只写事实不写结论>

## 决策

<最终决定：做什么、不做什么、关键设计点；正向表述，可引用实现位置>

## 备选方案

| 方案 | 理由 | 否决原因 |
|------|------|----------|
| <方案 A（最终选择）> | <优点> | — |
| <方案 B> | <优点> | <否决原因，越具体越好> |

## 后果

### 正面

- <长期收益，逐条>

### 负面

- <代价与限制，逐条；需后续偿还的登记到 [../workflows/debt.md](../workflows/debt.md)>

## 相关链接

- <需求条目 / 实现 PR / 调研报告 / 相关文档>
````

## 字段填写说明

| 字段 | 填写要求 | 反例（违反后果） |
|------|----------|------------------|
| 状态 | 单选：提议 / 已接受 / 已废弃 / 被替代 | 状态不清 → 误读决策是否生效 |
| 上下文 | 只写事实与约束，不写结论 | 缺上下文 → 后人无法判断决策是否仍适用 |
| 决策 | 正向表述、可执行、引用实现位置 | 模糊决策 → 实现漂移 |
| 备选方案 | 至少 1 个被否决方案，否决原因写具体（成本/风险/依赖） | 无备选 → 无法确认决策经过权衡 |
| 后果（负面） | 每条评估是否登记 [../workflows/debt.md](../workflows/debt.md) | 代价遗忘 → 债务无记录 |
| 相关链接 | 指向需求条目 / PR / 调研，保证可追溯 | 孤立决策 → 溯源断裂 |

## 状态流转

```
提议 ──接受──▶ 已接受
  │              │
  └─否决/放弃──▶ 已废弃 ◀──被新决策替代── 被替代
```

| 状态 | 含义 | 触发 |
|------|------|------|
| 提议 | 决策待确认，未生效 | 新决策提出时 |
| 已接受 | 生效中，实现按此执行 | 决策确认后 |
| 被替代 | 被新 ADR 取代，仍可追溯 | 新 ADR 显式引用替代时 |
| 已废弃 | 不再适用，实现已移除 | 决策失效 / 回退时 |

## 写作纪律

| # | 规则 | 违反后果 |
|---|------|----------|
| 1 | 每条 ADR 只记录一个决策 | 混合决策 → 状态流转失效 |
| 2 | 决策与实现代码同一 commit 记录 | 事后补写 → 记忆失真 |
| 3 | 被替代的 ADR 在新 ADR 中显式引用 | 隐性替代 → 旧决策误导后人 |
| 4 | 承重级决策（影响依赖方向 / 数据格式 / 签名体系）完成后同步更新 [../standards/architecture.md](../standards/architecture.md) | 承重规则与决策脱节 → 规则过期 |
