# 验证节点模板（Verification Node）

> 多步验证的可复现记录骨架：一个节点 = 一个可独立执行的操作序列 + 断言 + 证据。用于组织证据链与并行委派。

## Use when

- 组织多步验证、需要可复现记录时
- 并行委派验证节点给 subagent 时（每节点一份）

## 模板本体

```markdown
## 验证节点：<名称>
- 环境：<设备> · <应用版本> · <服务器版本>
- 前置：<服务器已连接 / 会话已存在 / 数据已就绪>
- 步骤：
  1. <操作 1>
  2. <操作 2>
- 通过标准：
  · <断言 1>（证据：<文件路径>）
  · <断言 2>（证据：<文件路径>）
- 交叉验证：<维度组合（构建/测试/运行时/遥测/人工 中 ≥2）>
- 失败路径：<未出现预期值时检查什么>
```

## 填写要求

| # | 要求 |
|---|------|
| 1 | 环境固定：记录设备/版本/网络拓扑 |
| 2 | 断言可机器核对：预期值写死，不写「正常」 |
| 3 | 网络异步类操作标注等待时长与重试策略 |
| 4 | 证据落盘路径写相对路径（可追溯） |
