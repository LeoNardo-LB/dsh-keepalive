# dsh-keepalive 人工验证清单（时间性现象）

> 自动化无法覆盖的 UI 时间性现象（verify.md §8）：倒计时连续性、面板刷新、布局稳定。
> 操作环境：本机 dsh web（插件已挂 profile web bundles）。逐条判定后反馈结果即可。

| # | 操作路径 | 预期现象 | 判定标准 |
|---|---------|---------|---------|
| 1 | 重启 dsh web → 打开 GUI → 看 composer 上方摘要条 | 出现 keepalive 摘要条：圆点 + "keepalive → <提供商>" + mm:ss 倒计时 | 倒计时每秒递减 1，连续无跳变、无重置回零 |
| 2 | 停留观察 ≥60s（或等一次发送完成） | 发送完成后倒计时切换为新一格（从 ~interval 重新开始倒数） | 切换瞬间无闪烁；✓ 标记出现（最近成功） |
| 3 | 点击摘要条 | shell.overlay 弹出全页面板（提供商卡片/历史/统计/配置） | 揭盖一次完成，无提前露底或二次跳动 |
| 4 | 面板内点「立即发送」 | 该提供商卡片：倒计时消失 → 数秒内「最近: ✓ xxms」出现 → 倒计时重新开始 | 全程卡片高度稳定，无布局跳动 |
| 5 | 切到「历史」tab | 出现发送记录表（时间/提供商/结果/延迟/内容） | 行追加时无滚动抖动；内容列显示 短语+时间戳+hex |
| 6 | 修改基准间隔 → 保存 | 摘要条倒计时按新间隔重新计算 | 保存后 ≤5s 生效（下一次轮询周期内） |
| 7 | 总开关关→开 | 关：倒计时消失显示"未启用"；开：恢复倒计时 | 状态切换 ≤5s，无中间错误态闪烁 |
| 8 | 点「关闭 ✕」或遮罩空白处 | 面板收起，摘要条仍在 | 收起一次完成，摘要条不移位 |

判定反馈格式：#编号 通过/失败（失败附一句现象描述）。
