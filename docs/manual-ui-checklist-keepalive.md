# dsh-keepalive 人工验证清单（时间性现象）

> 自动化无法覆盖的 UI 时间性现象（verify.md §8）：倒计时连续性、页签切换、弹层揭盖。
> 操作环境：本机 dsh web（插件已挂 profile web bundles）。逐条判定后反馈结果即可。

| # | 操作路径 | 预期现象 | 判定标准 |
|---|---------|---------|---------|
| 1 | 打开设置 → 插件区 → 点「提供商保活」页签 | 页签内容一次渲染完成：配置表单 + 提供商卡片 | 无白屏闪烁、无二次布局跳动 |
| 2 | 停留观察 ≥60s（或等一次发送完成） | 活跃提供商卡片倒计时每秒递减 1 | 连续无跳变、无重置回零；发送完成后倒计时从新间隔重新开始 |
| 3 | 点「立即发送」 | 该卡片：倒计时消失 → 数秒内「最近: ✓ xxms」出现 → 新倒计时开始 | 全程卡片高度稳定，无布局跳动 |
| 4 | 切「历史」→ 点任意行「查看」 | 弹层一次揭盖完成，显示发送内容 + 模型回复 | 揭盖无提前露底；长回复可滚动，滚动无抖动 |
| 5 | 点弹层「关闭 ✕」或遮罩空白处 | 弹层收起回到历史表 | 收起一次完成，表格位置不变 |
| 6 | 修改基准间隔 → 保存 | 卡片倒计时按新间隔重新计算 | 保存后 ≤5s 生效（下一次轮询周期内），无中间错误态 |
| 7 | 模型下拉换一项 → 保存模型 | 下拉值保持为已选项（外部轮询不回跳） | 保存后下拉不被轮询重置；总开关关→开同理 |
| 8 | 切「统计」再切回「提供商」 | 统计表与卡片均正常重渲染 | 两个方向切换各两次，无闪烁、无滚动位置丢失 |

判定反馈格式：#编号 通过/失败（失败附一句现象描述）。
