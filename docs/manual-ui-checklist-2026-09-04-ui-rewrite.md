# 人工验证清单 — UI 重写批次（2026-09-04-ui-rewrite-dsh-primitives）

> 环境：本地 GUI（127.0.0.1:3080，刷新页面后进入 设置 → 插件 → 提供商保活）
> 自动化已覆盖静态与交互断言（docker e2e browser-check v5）；本清单只验**时间性现象**（verify.md §8 / ui-conventions §5.5）。
> 判定结果请逐条标注 ✅/❌，❌ 附一句话现象描述。

| # | 操作路径 | 预期现象 | 判定标准 |
|---|---------|---------|---------|
| 1 | 打开保活 tab 后观察任一活跃卡片倒计时 | 秒数平滑递减（mm:ss → 下一秒），每秒走一格 | 全程连续递减；5s 轮询刷新时数字不回跳、不闪变 |
| 2 | 等 5s 轮询周期跨越（观察 10 秒） | 状态快照刷新时卡片无布局跳动、倒计时不重置 | 视口零跳动；倒计时读数单调不增 |
| 3 | 点「参与保活」等任一变更按钮 | 右下/顶部 Toast 横幅弹出 → 数秒后自行消失 | 横幅出现与消失各只发生一次；消失过程无闪烁 |
| 4 | 展开「历史（N）」折叠区 | 折叠动画一次完成，行列表逐步呈现 | 揭盖一次完成、无提前露底、无二次抖动 |
| 5 | 点开一条历史行（就地展开回复） | 展开过程平滑，回复文本区块无跳变 | 展开后视口不滚动跳位；再点收起一次完成 |
| 6 | 点「⋯」菜单 → 移除配置 | RiskConfirmation 就地出现；勾选确认前「移除」置灰 | 确认按钮仅在勾选后可点；取消后区块就地消失 |
| 7 | 切换系统浅色/深色主题（DSH 设置里） | 保活面板颜色随宿主主题即时切换 | 全部颜色跟切；无残留旧色、无花屏；两主题下文字均可读 |
| 8 | 浏览器开启「减少动态效果」（prefers-reduced-motion）后重复 4/5 | 折叠/展开转为无动画即时切换 | 无过渡动画播放；功能不受影响 |

## 备注

- 第 7 条为本次重写新增的跟随能力（旧 UI 硬编码暗色，浅色下必炸）；第 8 条为 ui-conventions §5.8 合规项（本 UI 自定义动效为零，仅折叠过渡由宿主组件承担）。
